# 🎯 PICO-8 Carrom Game

A PICO-8 carrom-style physics game where you control a striker, aim, and shoot to pocket pieces into the corner holes — built entirely in Lua for the PICO-8 fantasy console.

---

## 🕹️ How to Play

- **Move Striker:** ⬅️ / ➡️  
- **Confirm Position:** 🅾️  
- **Aim:** ⬅️ / ➡️ (rotate aim direction)  
- **Adjust Power:** ⬆️ / ⬇️  
- **Shoot:** 🅾️  
- **Cancel Aim:** ❎  

Pocket all the pieces just like in real carrom!  
White, black, and red pucks behave with real collision and friction physics.

---

## ⚙️ Features

- Physics-based piece movement  
- Collision and rebound system  
- Pocket (hole) detection  
- Animated striker return  
- Smooth easing animations for piece placement  
- Power-based aiming  
- Visual feedback for shot strength  
- Sound effects for collisions and pocketing  

---
